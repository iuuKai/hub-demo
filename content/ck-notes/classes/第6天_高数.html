不定积分

一、原函数与不定积分的概念

原函数的定义：如果在区间I上，可导函数 $F(x)$ 的导数为 $f(x)$，即对任一 $x \in I$，都有 $F'(x) = f(x)$，则称 $F(x)$ 是 $f(x)$ 在区间I上的一个原函数。

原函数存在定理：如果函数 $f(x)$ 在区间I上连续，则 $f(x)$ 在区间I上一定存在原函数。
（初等函数在其定义域内都连续，所以都有原函数）

不定积分的定义：函数 $f(x)$ 的全体原函数叫做 $f(x)$ 的不定积分，记作：
$\int f(x) dx = F(x) + C$

其中：
- $\int$ 叫做积分号
- $f(x)$ 叫做被积函数
- $f(x)dx$ 叫做被积表达式
- $x$ 叫做积分变量
- $C$ 叫做积分常数（任意常数）

为什么要加C？因为常数的导数是0，所以 $F(x)+C$ 的导数都是 $f(x)$，C可以是任意常数，代表全体原函数。
例题：验证 $F(x) = x^2$ 是 $f(x) = 2x$ 的一个原函数
解：$F'(x) = (x^2)' = 2x = f(x)$，所以 $x^2$ 是 $2x$ 的一个原函数
$2x$ 的全体原函数为 $\int 2x dx = x^2 + C$

二、不定积分的性质

性质1（求导和积分互逆）：
① $(\int f(x) dx)' = f(x)$（先积分后求导，等于原函数）
② $\int f'(x) dx = f(x) + C$（先求导后积分，等于原函数加C）

性质2（数乘）：$\int k f(x) dx = k \int f(x) dx$（k为常数，k≠0）

性质3（和差）：$\int [f(x) \pm g(x)] dx = \int f(x) dx \pm \int g(x) dx$
（和差的积分等于积分的和差，可以逐项积分）

三、基本积分公式（必须背熟，是求导公式的逆运算）

① $\int k dx = kx + C$（k为常数）

② $\int x^n dx = \frac{x^{n+1}}{n+1} + C$（$n \neq -1$，幂函数积分：指数加1，除以新指数）

③ $\int \frac{1}{x} dx = \ln|x| + C$（注意绝对值！）

④ $\int e^x dx = e^x + C$

⑤ $\int a^x dx = \frac{a^x}{\ln a} + C$（$a > 0, a \neq 1$）

⑥ $\int \sin x dx = -\cos x + C$（注意负号！）

⑦ $\int \cos x dx = \sin x + C$

⑧ $\int \sec^2 x dx = \tan x + C$

⑨ $\int \csc^2 x dx = -\cot x + C$

⑩ $\int \frac{1}{\sqrt{1-x^2}} dx = \arcsin x + C$

⑪ $\int \frac{1}{1+x^2} dx = \arctan x + C$
例题1：求 $\int x^3 dx$
解：用公式②，$n=3$：$\int x^3 dx = \frac{x^{3+1}}{3+1} + C = \frac{x^4}{4} + C$
例题2：求 $\int \sqrt{x} dx$
解：$\sqrt{x} = x^{\frac{1}{2}}$，用公式②：
$\int x^{\frac{1}{2}} dx = \frac{x^{\frac{1}{2}+1}}{\frac{1}{2}+1} + C = \frac{x^{\frac{3}{2}}}{\frac{3}{2}} + C = \frac{2}{3}x^{\frac{3}{2}} + C$
例题3：求 $\int \frac{1}{x^2} dx$
解：$\frac{1}{x^2} = x^{-2}$，用公式②：
$\int x^{-2} dx = \frac{x^{-2+1}}{-2+1} + C = \frac{x^{-1}}{-1} + C = -\frac{1}{x} + C$
例题4：求 $\int (2x^3 - \sin x + e^x) dx$
解：逐项积分：
$\int 2x^3 dx = 2 \cdot \frac{x^4}{4} = \frac{x^4}{2}$
$\int (-\sin x) dx = -(-\cos x) = \cos x$
$\int e^x dx = e^x$
所以原式 = $\frac{x^4}{2} + \cos x + e^x + C$
例题5：求 $\int (x^2 + 3x - 2) dx$
解：$\int x^2 dx = \frac{x^3}{3}$
$\int 3x dx = 3 \cdot \frac{x^2}{2} = \frac{3x^2}{2}$
$\int (-2) dx = -2x$
所以原式 = $\frac{x^3}{3} + \frac{3x^2}{2} - 2x + C$

四、换元积分法（第一类换元法，凑微分法）

基本思想：当被积函数是复合函数时，把复合函数的内层部分凑到微分号里，变成基本积分公式的形式。

公式：$\int f(\varphi(x)) \varphi'(x) dx = \int f(u) du$（令 $u = \varphi(x)$）

常见凑微分形式：
① $f(ax+b) \cdot a dx = f(ax+b) d(ax+b)$
② $f(x^n) \cdot x^{n-1} dx = \frac{1}{n} f(x^n) d(x^n)$
③ $f(e^x) \cdot e^x dx = f(e^x) d(e^x)$
④ $f(\ln x) \cdot \frac{1}{x} dx = f(\ln x) d(\ln x)$
⑤ $f(\sin x) \cdot \cos x dx = f(\sin x) d(\sin x)$
⑥ $f(\cos x) \cdot (-\sin x) dx = f(\cos x) d(\cos x)$
例题1：求 $\int (2x+1)^5 dx$
解：看到 $(2x+1)^5$，内层是 $2x+1$，导数是2，凑微分：
$\int (2x+1)^5 dx = \frac{1}{2} \int (2x+1)^5 d(2x+1)$
令 $u = 2x+1$，则 $\frac{1}{2} \int u^5 du = \frac{1}{2} \cdot \frac{u^6}{6} + C = \frac{u^6}{12} + C$
代回 $u = 2x+1$：$\frac{(2x+1)^6}{12} + C$
例题2：求 $\int \sin(3x) dx$
解：$\int \sin(3x) dx = \frac{1}{3} \int \sin(3x) d(3x) = \frac{1}{3}(-\cos 3x) + C = -\frac{1}{3}\cos 3x + C$
例题3：求 $\int x e^{x^2} dx$
解：看到 $e^{x^2}$，内层是 $x^2$，导数是 $2x$，而被积函数有 $x$：
$\int x e^{x^2} dx = \frac{1}{2} \int e^{x^2} d(x^2) = \frac{1}{2} e^{x^2} + C$
例题4：求 $\int \frac{\ln x}{x} dx$
解：看到 $\ln x$，导数是 $\frac{1}{x}$，而被积函数有 $\frac{1}{x}$：
$\int \frac{\ln x}{x} dx = \int \ln x \cdot \frac{1}{x} dx = \int \ln x \, d(\ln x) = \frac{(\ln x)^2}{2} + C$
例题5：求 $\int \frac{1}{2x+1} dx$
解：$\int \frac{1}{2x+1} dx = \frac{1}{2} \int \frac{1}{2x+1} d(2x+1) = \frac{1}{2} \ln|2x+1| + C$

五、分部积分法

公式：$\int u dv = uv - \int v du$

适用情况：被积函数是两种不同类型函数的乘积（如多项式×指数、多项式×三角、多项式×对数等）

选u的原则（反对幂指三）：
按"反三角函数、对数函数、幂函数、指数函数、三角函数"的顺序，排在前面的选作u，排在后面的和dx凑成dv
（即：反三角 > 对数 > 幂函数 > 指数 > 三角，优先选前面的为u）

步骤：
① 选u和dv（把容易积分的部分和dx凑成dv）
② 求du（对u求导）和v（对dv积分）
③ 代入公式 $\int u dv = uv - \int v du$
④ 计算 $\int v du$
例题1：求 $\int x e^x dx$
解：幂函数×指数，按"反对幂指三"，幂函数在前，选 $u = x$
$u = x$，$dv = e^x dx$
$du = dx$，$v = e^x$
代入公式：$\int x e^x dx = x e^x - \int e^x dx = x e^x - e^x + C$
例题2：求 $\int x \sin x dx$
解：幂函数×三角，幂函数在前，选 $u = x$
$u = x$，$dv = \sin x dx$
$du = dx$，$v = -\cos x$
代入公式：$\int x \sin x dx = x(-\cos x) - \int (-\cos x) dx = -x\cos x + \int \cos x dx = -x\cos x + \sin x + C$
例题3：求 $\int \ln x dx$
解：对数函数，选 $u = \ln x$，$dv = dx$
$du = \frac{1}{x} dx$，$v = x$
代入公式：$\int \ln x dx = x \ln x - \int x \cdot \frac{1}{x} dx = x \ln x - \int 1 dx = x \ln x - x + C$
例题4：求 $\int x^2 e^x dx$
解：选 $u = x^2$，$dv = e^x dx$
$du = 2x dx$，$v = e^x$
$\int x^2 e^x dx = x^2 e^x - \int 2x e^x dx = x^2 e^x - 2 \int x e^x dx$
对 $\int x e^x dx$ 再用一次分部积分（例题1已算出 $= x e^x - e^x$）：
原式 = $x^2 e^x - 2(x e^x - e^x) + C = x^2 e^x - 2x e^x + 2e^x + C = (x^2 - 2x + 2)e^x + C$

六、积分方法选择总结

① 基本公式直接用：被积函数就是基本积分公式中的形式

② 先化简再积分：被积函数可以展开、约分、化为幂函数形式
例：$\int \frac{x^2+1}{x} dx = \int (x + \frac{1}{x}) dx = \frac{x^2}{2} + \ln|x| + C$

③ 凑微分法（第一类换元）：被积函数是复合函数，且内层函数的导数在被积函数中（或差一个常数因子）

④ 分部积分法：被积函数是两种不同类型函数的乘积
