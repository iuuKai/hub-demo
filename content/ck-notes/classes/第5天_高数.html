导数的应用

一、函数的单调性

判定定理：设函数 $y=f(x)$ 在区间 $(a,b)$ 内可导：
① 如果在 $(a,b)$ 内 $f'(x) > 0$，则 $f(x)$ 在 $(a,b)$ 内单调递增（↗）
② 如果在 $(a,b)$ 内 $f'(x) < 0$，则 $f(x)$ 在 $(a,b)$ 内单调递减（↘）
③ 如果在 $(a,b)$ 内 $f'(x) = 0$，则 $f(x)$ 在 $(a,b)$ 内为常数

驻点：使 $f'(x) = 0$ 的点叫做函数的驻点（稳定点）

求单调区间的步骤：
① 求导数 $f'(x)$
② 令 $f'(x) = 0$，求出驻点
③ 用驻点把定义域分成若干区间
④ 在每个区间内取测试点，判断 $f'(x)$ 的正负
⑤ 根据正负确定单调递增或递减
例题：求 $f(x) = x^2 - 4x + 3$ 的单调区间
解：
① 求导：$f'(x) = 2x - 4$
② 令 $f'(x) = 0$：$2x - 4 = 0$，得 $x = 2$（驻点）
③ 分区间：$(-\infty, 2)$ 和 $(2, +\infty)$
④ 测试：
$x < 2$ 时（取 $x=0$），$f'(0) = -4 < 0$，单调递减
$x > 2$ 时（取 $x=3$），$f'(3) = 2 > 0$，单调递增
⑤ 结论：在 $(-\infty, 2)$ 上单调递减，在 $(2, +\infty)$ 上单调递增
例题：求 $f(x) = x^3 - 3x$ 的单调区间
解：
① $f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x+1)(x-1)$
② 令 $f'(x) = 0$：$x = -1$，$x = 1$
③ 分区间：$(-\infty, -1)$、$(-1, 1)$、$(1, +\infty)$
④ 测试：
$x < -1$（取 $x=-2$）：$f'(-2) = 9 > 0$，递增
$-1 < x < 1$（取 $x=0$）：$f'(0) = -3 < 0$，递减
$x > 1$（取 $x=2$）：$f'(2) = 9 > 0$，递增
⑤ 结论：在 $(-\infty, -1)$ 和 $(1, +\infty)$ 上递增，在 $(-1, 1)$ 上递减

二、函数的极值

极值的定义：
极大值：在 $x_0$ 附近，$f(x_0)$ 比周围的函数值都大
极小值：在 $x_0$ 附近，$f(x_0)$ 比周围的函数值都小

极值的必要条件：可导函数在极值点处必有 $f'(x_0) = 0$（即可导的极值点一定是驻点）
（注意：驻点不一定是极值点，如 $y=x^3$ 在 $x=0$ 处是驻点但不是极值点）

第一充分条件（左右导数变号法）：
① 左增右减（$f'$ 由正变负）→ 极大值
② 左减右增（$f'$ 由负变正）→ 极小值
③ 左右不变号 → 不是极值

第二充分条件（二阶导数法）：
设 $f'(x_0) = 0$：
① $f''(x_0) < 0$ → $f(x_0)$ 是极大值
② $f''(x_0) > 0$ → $f(x_0)$ 是极小值
③ $f''(x_0) = 0$ → 无法判断，需用第一充分条件
例题：求 $f(x) = x^3 - 3x^2 + 1$ 的极值
解：
① 求导：$f'(x) = 3x^2 - 6x = 3x(x-2)$
② 令 $f'(x) = 0$：$x = 0$，$x = 2$（驻点）
③ 求二阶导：$f''(x) = 6x - 6$
④ 判断：
$x = 0$：$f''(0) = -6 < 0$ → 极大值，$f(0) = 1$
$x = 2$：$f''(2) = 6 > 0$ → 极小值，$f(2) = 8 - 12 + 1 = -3$
⑤ 结论：极大值为 $f(0)=1$，极小值为 $f(2)=-3$
例题：求 $f(x) = 2x^3 - 6x^2 + 5$ 的极值
解：
① $f'(x) = 6x^2 - 12x = 6x(x-2)$
② 驻点：$x = 0$，$x = 2$
③ $f''(x) = 12x - 12$
④ $x=0$：$f''(0) = -12 < 0$ → 极大值 $f(0) = 5$
$x=2$：$f''(2) = 12 > 0$ → 极小值 $f(2) = 16 - 24 + 5 = -3$

三、闭区间上的最大值和最小值

步骤：
① 求导数 $f'(x)$
② 令 $f'(x) = 0$，求出区间内的驻点
③ 计算驻点处的函数值和端点处的函数值
④ 比较这些值的大小，最大的就是最大值，最小的就是最小值

注意：极值是局部概念，最值是整体概念；闭区间上的最值可能在驻点或端点处取得
例题：求 $f(x) = x^3 - 3x + 1$ 在 $[0, 3]$ 上的最大值和最小值
解：
① $f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$
② 令 $f'(x) = 0$：$x = -1$（不在区间内，舍去），$x = 1$
③ 计算函数值：
驻点：$f(1) = 1 - 3 + 1 = -1$
左端点：$f(0) = 0 - 0 + 1 = 1$
右端点：$f(3) = 27 - 9 + 1 = 19$
④ 比较：最大值为 $f(3) = 19$，最小值为 $f(1) = -1$

四、曲线的切线方程和法线方程

切线斜率：$k = f'(x_0)$

切线方程（点斜式）：$y - y_0 = f'(x_0)(x - x_0)$
其中 $(x_0, y_0)$ 是切点坐标，$y_0 = f(x_0)$

法线方程：法线与切线垂直，斜率为切线斜率的负倒数
$y - y_0 = -\frac{1}{f'(x_0)}(x - x_0)$（$f'(x_0) \neq 0$）

点斜式公式回顾：已知直线过点 $(x_0, y_0)$，斜率为k，则直线方程为 $y - y_0 = k(x - x_0)$
例题：求曲线 $y = x^2$ 在点 $(1, 1)$ 处的切线方程和法线方程
解：
① 求导：$y' = 2x$
② 切线斜率：$k = y'|_{x=1} = 2(1) = 2$
③ 切线方程：$y - 1 = 2(x - 1)$，即 $y = 2x - 1$
④ 法线斜率：$k_{法} = -\frac{1}{2}$
⑤ 法线方程：$y - 1 = -\frac{1}{2}(x - 1)$，即 $y = -\frac{1}{2}x + \frac{3}{2}$
例题：求曲线 $y = \ln x$ 在 $x = e$ 处的切线方程
解：
① 切点：$x = e$ 时，$y = \ln e = 1$，切点为 $(e, 1)$
② 求导：$y' = \frac{1}{x}$
③ 斜率：$k = y'|_{x=e} = \frac{1}{e}$
④ 切线方程：$y - 1 = \frac{1}{e}(x - e)$，即 $y = \frac{x}{e}$

五、曲线的凹凸性和拐点

凹凸性判定：
① $f''(x) > 0$ → 曲线是凹的（∪，向上凹）
② $f''(x) < 0$ → 曲线是凸的（∩，向上凸）

拐点：曲线凹凸性发生改变的点叫做拐点
拐点处 $f''(x) = 0$ 或 $f''(x)$ 不存在，且左右两侧 $f''(x)$ 变号

求拐点步骤：
① 求二阶导数 $f''(x)$
② 令 $f''(x) = 0$，求出候选点
③ 判断候选点左右 $f''(x)$ 是否变号
④ 变号则是拐点，不变号则不是
例题：求 $f(x) = x^3 - 3x^2 + 1$ 的凹凸区间和拐点
解：
① $f'(x) = 3x^2 - 6x$，$f''(x) = 6x - 6 = 6(x-1)$
② 令 $f''(x) = 0$：$x = 1$
③ 判断：
$x < 1$ 时，$f''(x) < 0$，凸的
$x > 1$ 时，$f''(x) > 0$，凹的
④ $x = 1$ 处凹凸性改变，是拐点
$f(1) = 1 - 3 + 1 = -1$，拐点为 $(1, -1)$
