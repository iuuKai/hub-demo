一、被动语态

1. 什么是被动语态？

主动语态：主语发出动作 → 主动句（主语是动作的执行者）
被动语态：主语承受动作 → 被动句（主语是动作的承受者）

主动：Tom cleans the room.（汤姆打扫房间）
被动：The room is cleaned by Tom.（房间被汤姆打扫）

2. 被动语态结构

基本结构：be + 过去分词（done）

不同时态的被动：
时态主动被动
一般现在时do/doesam/is/are + done
一般过去时didwas/were + done
一般将来时will dowill be + done
现在进行时am/is/are doingam/is/are being + done
现在完成时have/has donehave/has been + done

3. 被动语态用法

- 不知道动作的执行者：The window was broken.（窗户被打破了，不知道谁打破的）
- 不必说出动作的执行者：The book was written in 1990.（这本书写于1990年）
- 强调动作的承受者：The bridge was built in 1990.（这座桥建于1990年，强调桥）

by + 执行者：如果需要说出动作执行者，用by引出

4. 主动变被动步骤

步骤1：把主动句的宾语变为主语
步骤2：把动词变为"be + 过去分词"（时态不变）
步骤3：把主动句的主语变为by的宾语

例：主动 → They build the bridge.（他们建这座桥）
→ 被动 → The bridge is built by them.

5. 例题

例1：The letter ____ (write) yesterday.
解析：yesterday → 一般过去时；letter是被写 → 被动
答案：was written

例2：The classroom ____ (clean) every day.
解析：every day → 一般现在时；classroom是被打扫 → 被动
答案：is cleaned

例3：The work ____ (do) tomorrow.
解析：tomorrow → 一般将来时；work是被做 → 被动
答案：will be done

二、非谓语动词（不定式）

1. 什么是非谓语动词？

一个句子只能有一个谓语动词，其他动词要用非谓语形式。

非谓语有三种：
- 不定式：to + 动词原形
- 动名词：动词-ing
- 分词：动词-ing / 动词-ed

今天重点学：不定式（to do）

2. 不定式的用法

① 作宾语（动词+to do）：
want to do（想要做）, hope to do（希望做）, decide to do（决定做）
plan to do（计划做）, would like to do（想要做）

② 作宾语补足语（动词+sb+to do）：
ask sb to do（要求某人做）, tell sb to do（告诉某人做）
want sb to do（想要某人做）

③ 疑问词+不定式（what to do / how to do）：
I don't know what to do.（我不知道做什么）
She doesn't know how to do it.（她不知道怎么做）

3. 省略to的情况

使役动词后省略to：
make sb do（让某人做）, let sb do（让某人做）, have sb do（让某人做）

例：The boss made him work all day.（老板让他工作一整天）

感官动词后省略to：
see sb do（看见某人做）, hear sb do（听见某人做）

help可带to也可省略to：help sb (to) do

4. 例题

例1：I hope ____ (see) you soon.
解析：hope to do → 答案：to see

例2：He decided ____ (study) hard.
解析：decide to do → 答案：to study

例3：The teacher made me ____ (clean) the classroom.
解析：make sb do（省略to）→ 答案：clean
