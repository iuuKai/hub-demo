多元函数微分学

一、多元函数的基本概念

什么是多元函数？

一元函数：$y = f(x)$，只有一个自变量

多元函数：$z = f(x, y)$，有两个或更多自变量

例子：
- 长方形面积：$S = xy$（长x，宽y）
- 长方体体积：$V = xyz$（长x，宽y，高z）

二元函数的定义

设D是平面上的一个点集，如果对于每个点 $(x, y) \in D$，变量z按照一定法则总有确定的值和它对应，则称z是x, y的二元函数，记作 $z = f(x, y)$。

二、偏导数

什么是偏导数？

对多元函数求导时，只对一个变量求导，其他变量当作常数。

例子：$z = x^2 + 3xy + y^2$

对x求偏导（把y当常数）：
$\frac{\partial z}{\partial x} = 2x + 3y$

对y求偏导（把x当常数）：
$\frac{\partial z}{\partial y} = 3x + 2y$

偏导数的记号

记号读法
$\frac{\partial z}{\partial x}$z对x的偏导
$\frac{\partial z}{\partial y}$z对y的偏导
$f_x(x, y)$f对x的偏导
$f_y(x, y)$f对y的偏导
解题方法：求偏导和一元函数求导完全一样，只是把其他变量当常数。
例题1：求 $z = x^3 + y^3 - 2xy$ 的偏导数。
解：
对x求偏导（y当常数）：
$\frac{\partial z}{\partial x} = 3x^2 - 2y$

对y求偏导（x当常数）：
$\frac{\partial z}{\partial y} = 3y^2 - 2x$
例题2：求 $z = x^2 \sin y$ 的偏导数。
解：
对x求偏导（y当常数，$\sin y$是常数）：
$\frac{\partial z}{\partial x} = 2x \sin y$

对y求偏导（x当常数，$x^2$是常数）：
$\frac{\partial z}{\partial y} = x^2 \cos y$

三、二阶偏导数

对一阶偏导再求一次偏导，就是二阶偏导。

二阶偏导意思
$\frac{\partial^2 z}{\partial x^2}$对x求两次偏导
$\frac{\partial^2 z}{\partial y^2}$对y求两次偏导
$\frac{\partial^2 z}{\partial x \partial y}$先对x求偏导，再对y求偏导
$\frac{\partial^2 z}{\partial y \partial x}$先对y求偏导，再对x求偏导
重要结论：如果二阶混合偏导连续，则 $\frac{\partial^2 z}{\partial x \partial y} = \frac{\partial^2 z}{\partial y \partial x}$（和求导顺序无关）
例题3：求 $z = x^2 y + 3xy^3$ 的二阶偏导数。
解：
先求一阶偏导：
$\frac{\partial z}{\partial x} = 2xy + 3y^3$
$\frac{\partial z}{\partial y} = x^2 + 9xy^2$

再求二阶偏导：
$\frac{\partial^2 z}{\partial x^2} = 2y$
$\frac{\partial^2 z}{\partial y^2} = 18xy$
$\frac{\partial^2 z}{\partial x \partial y} = 2x + 9y^2$
$\frac{\partial^2 z}{\partial y \partial x} = 2x + 9y^2$

四、全微分

什么是全微分？

如果函数 $z = f(x, y)$ 的全增量可以表示为 $\Delta z = A\Delta x + B\Delta y + o(\rho)$，则称函数可微，全微分为：

$dz = \frac{\partial z}{\partial x} dx + \frac{\partial z}{\partial y} dy$
例题4：求 $z = x^2 y + y^2$ 的全微分。
解：
先求偏导：
$\frac{\partial z}{\partial x} = 2xy$
$\frac{\partial z}{\partial y} = x^2 + 2y$

全微分：
$dz = 2xy \, dx + (x^2 + 2y) \, dy$

五、核心公式汇总

类型公式
对x求偏导把y当常数，对x求导
对y求偏导把x当常数，对y求导
全微分$dz = \frac{\partial z}{\partial x} dx + \frac{\partial z}{\partial y} dy$
