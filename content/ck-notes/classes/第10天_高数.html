一、随机事件与概率

1. 基本概念

概念定义例子
随机试验结果不确定的试验掷骰子
样本空间所有可能结果的集合掷骰子：{1,2,3,4,5,6}
随机事件样本空间的子集掷出偶数：{2,4,6}
必然事件一定发生的事件掷出的点数≤6
不可能事件一定不发生的事件掷出点数=7

2. 概率的定义

概率就是事件发生的可能性大小，用P(A)表示，范围：
0 ≤ P(A) ≤ 1
- P(A) = 0：不可能发生
- P(A) = 1：一定发生
- P(A) = 0.5：一半一半

二、古典概型

1. 什么是古典概型？

满足两个条件：
1. 有限性：所有可能结果只有有限个
2. 等可能性：每个结果发生的可能性相等

2. 古典概型公式

P(A) = 事件A包含的基本事件数 / 总的基本事件数
例题1：掷一颗骰子，求掷出偶数的概率。

解：
- 总的基本事件数：6（1,2,3,4,5,6）
- 事件A（偶数）包含的基本事件数：3（2,4,6）
- P(A) = 3/6 = 1/2
例题2：从一副扑克牌（54张）中抽一张，求抽到红桃的概率。

解：
- 总的基本事件数：54
- 红桃有13张
- P(A) = 13/54

三、概率的基本公式

1. 加法公式（"或"）

P(A∪B) = P(A) + P(B) - P(A∩B)
特殊情况：如果A和B互斥（不能同时发生），则：
P(A∪B) = P(A) + P(B)

关键词："或"、"至少满足一个"
例题3：掷一颗骰子，求掷出偶数或点数大于4的概率。

解：
- A = 偶数：{2,4,6}，P(A) = 3/6 = 1/2
- B = 点数>4：{5,6}，P(B) = 2/6 = 1/3
- A∩B = 偶数且>4：{6}，P(A∩B) = 1/6
- P(A∪B) = 1/2 + 1/3 - 1/6 = 2/3

2. 乘法公式（"且"）

P(A∩B) = P(A) · P(B|A)
特殊情况：如果A和B独立（互不影响），则：
P(A∩B) = P(A) · P(B)

关键词："且"、"都发生"、"连续几次"
例题4：掷两次硬币，求两次都是正面的概率。

解：
- 第一次正面：P(A) = 1/2
- 第二次正面：P(B) = 1/2
- 两次独立，所以 P(A∩B) = 1/2 × 1/2 = 1/4

四、离散型随机变量

1. 什么是随机变量？

随机变量就是用数字表示随机试验的结果，通常用X、Y表示。

例子：掷一颗骰子，X = 掷出的点数，则X可以取1,2,3,4,5,6。

2. 分布列

X123456
P1/61/61/61/61/61/6
性质：所有概率加起来 = 1

五、期望与方差

1. 期望 E(X)（平均值）

E(X) = x₁p₁ + x₂p₂ + ... + xₙpₙ
就是每个结果乘以它的概率，加起来。
例题5：掷一颗骰子，求点数的期望。

解：
E(X) = 1×(1/6) + 2×(1/6) + 3×(1/6) + 4×(1/6) + 5×(1/6) + 6×(1/6)
= (1+2+3+4+5+6)/6 = 21/6 = 3.5

2. 方差 D(X)（波动大小）

D(X) = E(X²) - [E(X)]²
步骤：
1. 先算 E(X)（期望）
2. 再算 E(X²)（平方的期望）
3. 方差 = E(X²) - [E(X)]²

意义：方差越大，数据越分散；方差越小，越集中。
例子：

| X | 0 | 1 | 2 |
| P | 0.3 | 0.5 | 0.2 |

算E(X)：E(X) = 0×0.3 + 1×0.5 + 2×0.2 = 0.9

算E(X²)：E(X²) = 0²×0.3 + 1²×0.5 + 2²×0.2 = 1.3

算D(X)：D(X) = 1.3 - 0.9² = 1.3 - 0.81 = 0.49

六、核心公式汇总

类型公式
古典概型P(A) = 事件A的基本事件数 / 总基本事件数
加法公式（或）P(A∪B) = P(A) + P(B) - P(A∩B)
乘法公式（且）P(A∩B) = P(A) · P(B)（独立时）
期望E(X) = Σ xᵢpᵢ
方差D(X) = E(X²) - [E(X)]²
