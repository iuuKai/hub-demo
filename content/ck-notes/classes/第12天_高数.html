遗漏知识点补充（二）

一、闭区间上连续函数的性质

1. 最值定理

如果函数 $f(x)$ 在闭区间 $[a, b]$ 上连续，则 $f(x)$ 在 $[a, b]$ 上必有最大值和最小值。

2. 有界性定理

如果函数 $f(x)$ 在闭区间 $[a, b]$ 上连续，则 $f(x)$ 在 $[a, b]$ 上必有界。

3. 介值定理

如果函数 $f(x)$ 在闭区间 $[a, b]$ 上连续，且 $f(a) \neq f(b)$，则对于 $f(a)$ 与 $f(b)$ 之间的任意一个数 $C$，在 $(a, b)$ 内至少存在一点 $\xi$，使得 $f(\xi) = C$。

4. 零点定理（根的存在定理）⭐⭐⭐

如果函数 $f(x)$ 在闭区间 $[a, b]$ 上连续，且 $f(a) \cdot f(b) < 0$，则在 $(a, b)$ 内至少存在一点 $\xi$，使得 $f(\xi) = 0$。

用途：证明方程有根。
例题：证明方程 $x^3 - 4x^2 + 1 = 0$ 在 $(0, 1)$ 内至少有一个根。

证明：设 $f(x) = x^3 - 4x^2 + 1$
① $f(x)$ 在 $[0, 1]$ 上连续（多项式函数处处连续）
② $f(0) = 0 - 0 + 1 = 1 > 0$
③ $f(1) = 1 - 4 + 1 = -2 < 0$
④ 由零点定理，在 $(0, 1)$ 内至少存在一点 $\xi$，使得 $f(\xi) = 0$
即方程 $x^3 - 4x^2 + 1 = 0$ 在 $(0, 1)$ 内至少有一个根。

二、曲线的渐近线

1. 水平渐近线

如果 $\lim_{x \to +\infty} f(x) = A$ 或 $\lim_{x \to -\infty} f(x) = A$，则 $y = A$ 是曲线的水平渐近线。
例题：求 $y = \frac{1}{x}$ 的水平渐近线。
解：$\lim_{x \to \infty} \frac{1}{x} = 0$，所以 $y = 0$ 是水平渐近线。

2. 垂直渐近线

如果 $\lim_{x \to x_0^+} f(x) = \infty$ 或 $\lim_{x \to x_0^-} f(x) = \infty$，则 $x = x_0$ 是曲线的垂直渐近线。

判断方法：找分母为0且分子不为0的点。
例题：求 $y = \frac{x+1}{x-1}$ 的渐近线。

解：
垂直渐近线：令分母 $x-1 = 0$，得 $x = 1$，此时分子 $x+1 = 2 \neq 0$
当 $x \to 1$ 时，$y \to \infty$，所以 $x = 1$ 是垂直渐近线。

水平渐近线：$\lim_{x \to \infty} \frac{x+1}{x-1} = \lim_{x \to \infty} \frac{1+\frac{1}{x}}{1-\frac{1}{x}} = 1$
所以 $y = 1$ 是水平渐近线。

3. 斜渐近线（了解）

如果 $\lim_{x \to \infty} \frac{f(x)}{x} = a$ 且 $\lim_{x \to \infty} [f(x) - ax] = b$，则 $y = ax + b$ 是斜渐近线。

三、广义积分（反常积分）

1. 无穷限的广义积分

$\int_a^{+\infty} f(x) dx = \lim_{b \to +\infty} \int_a^b f(x) dx$

如果极限存在，称广义积分收敛；否则称发散。
例题：求 $\int_0^{+\infty} e^{-x} dx$

解：$\int_0^{+\infty} e^{-x} dx = \lim_{b \to +\infty} \int_0^b e^{-x} dx = \lim_{b \to +\infty} [-e^{-x}]_0^b = \lim_{b \to +\infty} (1 - e^{-b}) = 1$

所以广义积分收敛，值为1。

2. 无界函数的广义积分（了解）

如果 $f(x)$ 在 $(a, b]$ 上连续，且 $\lim_{x \to a^+} f(x) = \infty$，则
$\int_a^b f(x) dx = \lim_{\varepsilon \to 0^+} \int_{a+\varepsilon}^b f(x) dx$

四、条件极值与拉格朗日乘数法

1. 什么是条件极值？

无条件极值：对自变量只有定义域限制，没有其他约束条件。
条件极值：对自变量除了定义域限制外，还有附加约束条件。

2. 拉格朗日乘数法

求函数 $z = f(x, y)$ 在约束条件 $\varphi(x, y) = 0$ 下的极值。

构造拉格朗日函数：
$L(x, y, \lambda) = f(x, y) + \lambda \varphi(x, y)$

求偏导数并令其为0：
$\begin{cases} L_x = f_x(x, y) + \lambda \varphi_x(x, y) = 0 \\ L_y = f_y(x, y) + \lambda \varphi_y(x, y) = 0 \\ L_\lambda = \varphi(x, y) = 0 \end{cases}$

解出 $x, y, \lambda$，得到可能的极值点。
例题：求表面积为 $a^2$ 而体积最大的长方体的体积。

解：设长方体的长、宽、高分别为 $x, y, z$，则：
体积：$V = xyz$
约束条件：$2(xy + yz + zx) = a^2$，即 $xy + yz + zx = \frac{a^2}{2}$

构造拉格朗日函数：$L = xyz + \lambda(xy + yz + zx - \frac{a^2}{2})$

求偏导：
$\begin{cases} L_x = yz + \lambda(y + z) = 0 \\ L_y = xz + \lambda(x + z) = 0 \\ L_z = xy + \lambda(x + y) = 0 \\ L_\lambda = xy + yz + zx - \frac{a^2}{2} = 0 \end{cases}$

由前三式可得 $x = y = z$，即正方体时体积最大。
代入第四式：$3x^2 = \frac{a^2}{2}$，$x = \frac{a}{\sqrt{6}}$

最大体积：$V = x^3 = (\frac{a}{\sqrt{6}})^3 = \frac{a^3}{6\sqrt{6}} = \frac{\sqrt{6}a^3}{36}$
