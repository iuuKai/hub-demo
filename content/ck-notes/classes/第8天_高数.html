定积分的应用

一、定积分求平面图形的面积

定积分 $\int_a^b f(x) dx$ 的几何意义是：曲线 $f(x)$、x轴、直线 $x=a$、直线 $x=b$ 围成的面积。

上下型图形（最常考）

如果两条曲线 $y = f(x)$（上）和 $y = g(x)$（下）在 $[a, b]$ 之间围成一个图形，面积公式：

$S = \int_a^b [f(x) - g(x)] dx$
口诀：上减下
先求交点确定积分上下限，再判断哪条在上、哪条在下

解题步骤

① 求交点：令两条曲线相等，解出交点横坐标
② 判断上下：在区间内取一个点代入，看哪个函数值大
③ 代入公式：上曲线减下曲线，积分求面积
例题1：求由 $y = x^2$ 和 $y = x$ 围成的图形面积。
解：
第1步：令 $x^2 = x$ → $x^2 - x = 0$ → $x(x-1) = 0$ → $x = 0$ 或 $x = 1$，积分区间 $[0, 1]$
第2步：取 $x = 0.5$，$y = x^2 = 0.25$，$y = x = 0.5$，所以 $y = x$ 在上
第3步：$S = \int_0^1 (x - x^2) dx = \left[ \frac{1}{2}x^2 - \frac{1}{3}x^3 \right]_0^1 = \frac{1}{2} - \frac{1}{3} = \frac{1}{6}$
答案：$\frac{1}{6}$

二、旋转体体积

绕x轴旋转

由曲线 $y = f(x)$、$x = a$、$x = b$、$y = 0$ 围成的图形，绕x轴旋转一周所得旋转体体积：

$V = \pi \int_a^b [f(x)]^2 dx$
口诀：平方再乘π
例题2：求由 $y = x$、$x = 1$、$y = 0$ 绕x轴旋转的体积。
解：
$V = \pi \int_0^1 x^2 dx = \pi \left[ \frac{x^3}{3} \right]_0^1 = \frac{\pi}{3}$
答案：$\frac{\pi}{3}$

三、经济应用

边际成本与总成本

边际成本：成本函数的导数 $C'(x)$
总成本函数：$C(x) = \int C'(x) dx + C(0)$，其中 $C(0)$ 是固定成本

边际收益与总收益

边际收益：收益函数的导数 $R'(x)$
总收益函数：$R(x) = \int R'(x) dx$，其中 $R(0) = 0$
例题3：已知边际成本 $C'(x) = 2x + 10$，固定成本 $C(0) = 20$，求总成本函数。
解：
$C(x) = \int (2x + 10) dx = x^2 + 10x + C$
代入 $C(0) = 20$，得 $C = 20$
答案：$C(x) = x^2 + 10x + 20$

四、核心公式汇总

类型公式
平面图形面积（上下型）$S = \int_a^b [f(x) - g(x)] dx$
旋转体体积（绕x轴）$V = \pi \int_a^b [f(x)]^2 dx$
总成本函数$C(x) = \int C'(x) dx + C(0)$
总收益函数$R(x) = \int R'(x) dx$，$R(0) = 0$
