导数的概念与求导公式

一、导数的概念

导数的定义：设函数 $y=f(x)$ 在点 $x_0$ 的某邻域内有定义，当自变量 $x$ 在 $x_0$ 处取得增量 $\Delta x$ 时，相应地函数取得增量 $\Delta y = f(x_0+\Delta x) - f(x_0)$。如果 $\frac{\Delta y}{\Delta x}$ 当 $\Delta x \to 0$ 时的极限存在，则称函数 $f(x)$ 在点 $x_0$ 处可导，这个极限叫做 $f(x)$ 在点 $x_0$ 处的导数。
$f'(x_0) = \displaystyle\lim_{\Delta x \to 0} \frac{\Delta y}{\Delta x} = \lim_{\Delta x \to 0} \frac{f(x_0+\Delta x) - f(x_0)}{\Delta x}$
导数的几何意义：$f'(x_0)$ 表示曲线 $y=f(x)$ 在点 $(x_0, f(x_0))$ 处的切线的斜率。

切线方程：$y - f(x_0) = f'(x_0)(x - x_0)$（点斜式）

法线方程：$y - f(x_0) = -\frac{1}{f'(x_0)}(x - x_0)$（法线与切线垂直，斜率为负倒数）

可导与连续的关系：
① 可导一定连续
② 连续不一定可导（如 $y=|x|$ 在 $x=0$ 处连续但不可导）
③ 不连续一定不可导

二、基本求导公式（必须背熟）

① $(C)' = 0$（常数的导数为0）

② $(x^n)' = nx^{n-1}$（幂函数：指数拿下来当系数，指数减1）

③ $(ax)' = a$（一次函数的导数是系数a）

④ $(e^x)' = e^x$（e的x次方导数不变）

⑤ $(a^x)' = a^x \ln a$（一般指数函数）

⑥ $(\ln x)' = \frac{1}{x}$（自然对数）

⑦ $(\log_a x)' = \frac{1}{x \ln a}$（一般对数）

⑧ $(\sin x)' = \cos x$（正弦导数是余弦）

⑨ $(\cos x)' = -\sin x$（余弦导数是负正弦，注意负号！）

⑩ $(\tan x)' = \sec^2 x = \frac{1}{\cos^2 x}$

⑪ $(\cot x)' = -\csc^2 x = -\frac{1}{\sin^2 x}$
例题：求下列函数的导数
(1) $y = 5$（常数）→ $y' = 0$
(2) $y = x^3$ → $y' = 3x^{3-1} = 3x^2$
(3) $y = x^{10}$ → $y' = 10x^9$
(4) $y = \sqrt{x} = x^{\frac{1}{2}}$ → $y' = \frac{1}{2}x^{\frac{1}{2}-1} = \frac{1}{2}x^{-\frac{1}{2}} = \frac{1}{2\sqrt{x}}$
(5) $y = \frac{1}{x} = x^{-1}$ → $y' = -1 \cdot x^{-1-1} = -x^{-2} = -\frac{1}{x^2}$
(6) $y = 3x$ → $y' = 3$
(7) $y = \sin x$ → $y' = \cos x$
(8) $y = \cos x$ → $y' = -\sin x$

三、求导四则运算法则

设 $u=u(x)$，$v=v(x)$ 都可导，则：

① 和差：$(u \pm v)' = u' \pm v'$（和差的导数等于导数的和差）

② 数乘：$(Cu)' = Cu'$（常数可以提出来）

③ 乘法：$(uv)' = u'v + uv'$（前导后不导 + 前不导后导）

④ 除法：$(\frac{u}{v})' = \frac{u'v - uv'}{v^2}$（上导下不导 - 上不导下导，除以下面平方）
（除法口诀：分子导数乘分母 - 分子乘分母导数，再除以分母平方）
例题1：求 $y = x^2 - 2x + 5$ 的导数
解：$y' = (x^2)' - (2x)' + (5)' = 2x - 2 + 0 = 2x - 2$
例题2：求 $y = (2x+1)(x^2-3)$ 的导数
解：用乘法法则，设 $u=2x+1$，$v=x^2-3$
$u' = 2$，$v' = 2x$
$y' = u'v + uv' = 2(x^2-3) + (2x+1)(2x)$
$= 2x^2 - 6 + 4x^2 + 2x = 6x^2 + 2x - 6$
例题3：求 $y = \frac{x+1}{x-1}$ 的导数
解：用除法法则，设 $u=x+1$，$v=x-1$
$u' = 1$，$v' = 1$
$y' = \frac{u'v - uv'}{v^2} = \frac{1 \cdot (x-1) - (x+1) \cdot 1}{(x-1)^2}$
$= \frac{x-1-x-1}{(x-1)^2} = \frac{-2}{(x-1)^2}$

四、复合函数求导（链式法则）

法则：设 $y=f(u)$，$u=g(x)$，则复合函数 $y=f(g(x))$ 的导数为：
$y' = f'(u) \cdot g'(x)$（外层导数 × 内层导数）

记忆：从外到内一层层求导，像剥洋葱一样，每层导数相乘

步骤：
① 先设中间变量u，把复合函数拆成外层和内层
② 分别求外层导数和内层导数
③ 相乘，最后把u换回x的表达式
例题1：求 $y = \sin(3x)$ 的导数
解：设 $u = 3x$，则 $y = \sin u$
外层导数：$(\sin u)' = \cos u$
内层导数：$(3x)' = 3$
$y' = \cos u \cdot 3 = 3\cos(3x)$
例题2：求 $y = (2x+1)^3$ 的导数
解：设 $u = 2x+1$，则 $y = u^3$
外层导数：$(u^3)' = 3u^2$
内层导数：$(2x+1)' = 2$
$y' = 3u^2 \cdot 2 = 6(2x+1)^2$
例题3：求 $y = e^{x^2}$ 的导数
解：设 $u = x^2$，则 $y = e^u$
外层导数：$(e^u)' = e^u$
内层导数：$(x^2)' = 2x$
$y' = e^u \cdot 2x = 2x e^{x^2}$
例题4：求 $y = \ln(2x+1)$ 的导数
解：设 $u = 2x+1$，则 $y = \ln u$
外层导数：$(\ln u)' = \frac{1}{u}$
内层导数：$(2x+1)' = 2$
$y' = \frac{1}{u} \cdot 2 = \frac{2}{2x+1}$

五、高阶导数

二阶导数：对一阶导数再求导，记作 $y''$ 或 $f''(x)$ 或 $\frac{d^2y}{dx^2}$
n阶导数：对函数连续求n次导，记作 $y^{(n)}$ 或 $f^{(n)}(x)$

例：$y = x^3$
$y' = 3x^2$（一阶导数）
$y'' = 6x$（二阶导数）
$y''' = 6$（三阶导数）
$y^{(4)} = 0$（四阶导数）
