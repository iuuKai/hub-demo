错题 #001（薄弱点）

日期：2026-09-02

类型：因式分解

题目：将 $3x^2 - 12x + 9$ 因式分解

错误答案只能分解到 $3(x^2 - 4x + 3)$

正确答案$3(x - 1)(x - 3)$

错误原因十字相乘法不熟练，$x^2 - 4x + 3$ 可以继续分解

相关知识点因式分解——十字相乘法

复习状态：🔄 未掌握

知识点补充：
十字相乘法：$x^2 + (p+q)x + pq = (x+p)(x+q)$
- $x^2 - 4x + 3$：找两个数，乘积=3，和=-4 → -1 和 -3
- 所以 $x^2 - 4x + 3 = (x-1)(x-3)$
- 最终：$3x^2 - 12x + 9 = 3(x-1)(x-3)$

错题 #002（薄弱点）

日期：2026-09-02

类型：导数应用——切线方程

题目：求曲线在某点的切线方程

错误答案不记得点斜式公式

正确答案点斜式 $y - y_0 = f'(x_0)(x - x_0)$

错误原因高中解析几何知识遗忘，点斜式公式不记得

相关知识点导数的几何意义——切线斜率；直线的点斜式方程

复习状态：🔄 未掌握

知识点补充：
- 导数的几何意义：$f'(x_0)$ 是曲线 $y=f(x)$ 在点 $(x_0, f(x_0))$ 处的切线斜率
- 点斜式方程：$y - y_0 = k(x - x_0)$，其中 $k$ 是斜率，$(x_0, y_0)$ 是直线上一点
- 解题步骤：① 求导 $f'(x)$ ② 代入 $x_0$ 得斜率 $k=f'(x_0)$ ③ 用点斜式写方程

错题 #004（注意点）

日期：2026-09-05

类型：不定积分——三角函数

题目：涉及 $\sec$、$\cot$、$\csc$ 的积分

错误答案对 $\sec$、$\cot$、$\csc$ 不熟悉

正确答案需掌握 $\sec=1/\cos$, $\csc=1/\sin$, $\cot=1/\tan$

错误原因高中三角函数知识遗忘，$\sec/\csc/\cot$ 不熟悉

相关知识点三角函数定义、三角恒等式

复习状态：🔄 未掌握

三角函数速成卡：
- $\sec x = \frac{1}{\cos x}$（正割）
- $\csc x = \frac{1}{\sin x}$（余割）
- $\cot x = \frac{\cos x}{\sin x} = \frac{1}{\tan x}$（余切）
- 恒等式：$1 + \tan^2 x = \sec^2 x$，$1 + \cot^2 x = \csc^2 x$
- 求导：$(\tan x)' = \sec^2 x$，$(\cot x)' = -\csc^2 x$

错题 #005（薄弱点）

日期：2026-09-15

类型：多元函数——复合函数求偏导

题目：求 $z = e^{xy}$ 的一阶偏导数

错误答案$\frac{\partial z}{\partial x} = e^y$，$\frac{\partial z}{\partial y} = e^x$

正确答案$\frac{\partial z}{\partial x} = y e^{xy}$，$\frac{\partial z}{\partial y} = x e^{xy}$

错误原因复合函数求导漏乘内层函数的导数

相关知识点多元复合函数求偏导——链式法则

复习状态：🔄 未掌握

知识点补充：
复合函数求导（链式法则）：
- $z = e^{xy}$ 对x求偏导：先对 $e^u$ 求导得 $e^u$，再乘 $u=xy$ 对x的导数 $y$
- 所以：$\frac{\partial z}{\partial x} = e^{xy} \cdot y = y e^{xy}$
- 同理：$\frac{\partial z}{\partial y} = e^{xy} \cdot x = x e^{xy}$
口诀：外层求导 × 内层求导

错题 #006（薄弱点）

日期：2026-09-15

类型：多元函数——三角函数求导符号

题目：求 $z = x^2 y + \sin y$ 对y的偏导数

错误答案$\frac{\partial z}{\partial y} = x^2 - \cos y$

正确答案$\frac{\partial z}{\partial y} = x^2 + \cos y$

错误原因三角函数求导公式记错，$\sin$ 的导数符号搞反了

相关知识点基本求导公式——三角函数

复习状态：🔄 未掌握

知识点补充：
三角函数求导公式（必背）：
- $(\sin x)' = \cos x$（正→余，正号）
- $(\cos x)' = -\sin x$（余→正，负号）
对比记忆：$\sin$ 求导变 $\cos$，$\cos$ 求导变 $-\sin$

错题 #007（薄弱点）

日期：2026-10-15

类型：导数应用——曲线的渐近线

题目：求曲线 $y = \frac{x+1}{x-1}$ 的水平渐近线和垂直渐近线

错误答案垂直渐近线是 $x = 1$ 或 $x = -1$

正确答案垂直渐近线只有 $x = 1$，水平渐近线是 $y = 1$

错误原因垂直渐近线判断错误，误以为分子为0的点也是垂直渐近线

相关知识点曲线的渐近线——水平渐近线、垂直渐近线

复习状态：🔄 未掌握

知识点补充：
垂直渐近线判断方法：
1. 找分母为0的点（函数无定义的点）
2. 验证该点处分子是否不为0
  - 分子≠0 → y→∞，是垂直渐近线 ✅
  - 分子=0 → 0/0型，需要化简或求极限，不一定是渐近线

本题分析：
- 分母 $x-1 = 0$ → $x = 1$，此时分子 $x+1 = 2 \neq 0$ → $x=1$ 是垂直渐近线
- $x = -1$ 时，分子 $x+1 = 0$，分母 $x-1 = -2$，$y = 0$，不是无穷大 → 不是垂直渐近线

水平渐近线：
$\lim_{x \to \infty} \frac{x+1}{x-1} = \lim_{x \to \infty} \frac{1+\frac{1}{x}}{1-\frac{1}{x}} = 1$ → $y = 1$ 是水平渐近线
