- **错误答案**：答了三个要点，但表述偏口语化，理论表述不够规范
- **正确答案**：

  2. 意识对物质具有能动的反作用：正确的意识促进事物发展，错误的意识阻碍事物发展

- 简答题按"原理+方法论"结构作答

### 错题 #011（薄弱点）
- **日期**：2026-09-16
- **类型**：简答题——知识点混淆
- **题目**：用"矛盾普遍性和特殊性辩证关系"分析为什么要"中国特色社会主义"？
- **错误答案**：答成了"矛盾具有同一性和斗争性"
- **正确答案**：
  1. 矛盾的普遍性和特殊性相互联结：普遍性寓于特殊性之中，特殊性也离不开普遍性
  2. 矛盾的普遍性和特殊性在一定条件下可以相互转化
  3. 方法论：坚持普遍性与特殊性、共性与个性的具体的历史的统一
  4. 中国特色社会主义就是马克思主义基本原理（普遍性）同中国具体实际（特殊性）相结合的产物
- **错误原因**：混淆了矛盾的两个知识点——把"普遍性和特殊性"和"同一性和斗争性"搞混了
- **相关知识点**：矛盾的精髓（普遍性和特殊性）
- **复习状态**：🔄 未掌握

**知识点对比（必记）**：
- 矛盾的**基本属性** = 同一性 + 斗争性
- 矛盾的**精髓** = 普遍性 + 特殊性（共性 + 个性）

## 政治答题模板

### 选择题技巧
- 单选题：排除法（先排除明显错误的）
- 多选题：宁缺毋滥，不确定的选项不要选（多选错选不得分，少选得部分分）
- 注意题干中的"不正确的是""错误的是"等否定词

### 简答题模板
```
原理：（用规范术语写出理论原理，分点）
方法论：（写出对应的方法论要求）
结合材料/举例：（简单一句话说明）
```

### 辨析题模板
```
判断：此观点是正确的/错误的/片面的。
分析：
  ① 合理之处：...
  ② 不合理之处：...
  ③ 正确的说法应该是：...
总结：因此，该观点...
```
